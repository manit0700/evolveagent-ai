# EvolveAgent AI — Demo Video

`evolveagent_resume_saas_demo.mp4` (~72s, 1920×1200) is a captioned product walkthrough
recorded against the local dev app (backend `:8000`, frontend `:5173`) in mock mode.

**Positioning:** One prompt becomes a *governed full-project execution plan* (plan, phases,
task graph, agents, approval gates, governance/audit) — not a finished, deployed app. Output
in this demo is the governed plan/artifacts produced in mock mode.

## Prompt used

> Build a high-end AI resume analyzer SaaS with dashboard, upload flow, scoring, admin view, launch plan, and safety checks.

## Sections & captions

| Time | Screen | Caption |
|---|---|---|
| 0–6s | Home Dashboard | One prompt. Full project workflow. |
| 6–16s | Simple Mode Chat | Multi-agent orchestration & Master Agent routing |
| 16–30s | Orchestrator response | Planning, tools & verification |
| 30–46s | Mission Control | Mission Control builds the plan (progress 0% → 20% on approval) |
| 46–58s | Governance | Human approval + governance |
| 58–72s | Command Center | EvolveAgent: AI Operating System |

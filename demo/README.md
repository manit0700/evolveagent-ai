# EvolveAgent AI — Demo Video

`evolveagent_resume_saas_demo.mp4` (~52s, 1920×1200, fullscreen capture) is a captioned
product walkthrough recorded against the local dev app (backend `:8000`, frontend `:5173`)
in mock mode.

**Positioning:** One prompt becomes a *governed full-project execution plan* (phases, task
graph, specialist agents, approval gates, governance/audit) — not a finished, deployed app.
Output in this demo is the governed plan/artifacts produced in mock mode.

## Prompt used

> Build a high-end AI resume analyzer SaaS with dashboard, upload flow, scoring, admin view, launch plan, and safety checks.
